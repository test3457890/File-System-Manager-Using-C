# Project documentation

Welcome to the documentation for **File System Manager Using C**.

This directory provides a wiki-style guide that lives in the repository and can be reviewed alongside code changes.

## Start here

1. [Getting started](Getting-Started.md) — compile and run the current implementation.
2. [Commands](Commands.md) — use the virtual file manager.
3. [Architecture](Architecture.md) — understand the tree and linked-list model.
4. [Roadmap](Roadmap.md) — learn what is implemented and what is proposed.

The project is an educational, **in-memory simulation**. It never edits your computer's real directories. A native GitHub Wiki is a separate feature; these version-controlled Markdown pages provide similar documentation without requiring Wiki configuration.
